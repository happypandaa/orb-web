全局搜索让你可以在所有会话中查找内容，而不需要逐个会话翻阅。它是 OrbNote Pro 功能。

## 搜索范围

| 搜索对象 | 说明 |
| --- | --- |
| 消息正文 | 文本消息的内容 |
| 附件文本 | 文件名和附件元信息 |
| 图片 OCR | 通过 Vision 框架识别的图片文字 |
| 语音转写 | 通过[语音转文字](/zh/wiki/audio-transcription/)生成的转录文本 |
| 文章全文 | 长文本消息中的文章内容 |
| 待办列表 | 待办项的文本内容 |

## 使用搜索

1. 按 Cmd+F（macOS）打开搜索。
2. 输入关键词，结果实时更新。
3. 使用上下方向键在结果间导航。
4. 按 Enter 跳转到选中的消息。

## 搜索与隐私

搜索结果会自动排除[会话密码保护](/zh/wiki/conversation-password/)锁定的会话内容：

- 锁定状态的会话内容不出现在搜索结果中。
- 解锁后的会话内容才会被纳入搜索。
- 这保证了即使搜索时，敏感内容也不会被意外暴露。

## 免费与 Pro 的区别

| 用户类型 | 搜索能力 |
| --- | --- |
| 免费用户 | 基础消息内容搜索 |
| Pro 用户 | 全文搜索，包括附件 OCR、语音转写、文章全文 |

了解更多关于语音转写和隐私保护的内容，可以阅读[语音转文字](/zh/wiki/audio-transcription/)和[会话密码保护](/zh/wiki/conversation-password/)。
